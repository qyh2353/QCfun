# QCfun

**追动漫的小朋友~**

把发现作品、观看、阅读与交流放在同一个空间。QCfun 提供 Flutter Android 客户端，以本机运行时连接作品目录、可配置规则与个人媒体库，并将 AI 助手融入阅读和观影过程。

[下载 Android 安装包](https://github.com/qyh2353/QCfun/releases/latest) · [开始使用](GETTING_STARTED.md) · [常见问题](FAQ.md) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/qyh2353/QCfun/issues/new/choose)

## 在这里可以做什么

| 场景 | 功能 |
| --- | --- |
| 发现与整理 | 海报影院、分类筛选、时间表、片单、继续观看与相关作品 |
| 观看 | 竖屏与全屏、选集换源、来源测速、倍速与进度手势、小窗播放 |
| 阅读 | 漫画与小说、书架、阅读进度；支持配置模型进行翻译与漫画上色 |
| AI 助手 | 聊作品、查找应用内资源、上下文浮窗与外观建议；能力取决于配置模型与服务权限 |
| 社区 | 自定义账号注册登录、云弹幕、评论评分、好友私信与作品分享、个人数据备份 |

## 下载与安装

在 Releases 下载 `QCfun-Flutter-0.9.1-arm64.apk`。面向 **Android 8.0 及以上的 ARM64 设备**。更新同一应用时覆盖安装即可；卸载可能丢失未备份的本机数据。下载后可用同页的 `SHA256SUMS.txt` 校验文件。

本仓库主分支用于产品介绍、使用说明和问题反馈。每个正式版本的 Release 同时提供安装包与对应源码压缩包，源码包含 Flutter 客户端及其构建所需的共享运行时。GitHub 自动生成的 Source code 压缩包只包含本展示仓库；**完整对应源码请下载 `QCfun-0.9.1-corresponding-source.zip`**。
