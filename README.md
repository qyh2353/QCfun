# QCfun

### 看见好作品，把喜欢留久一点。

**QCfun 是一个围绕动漫与阅读打造的个人娱乐空间。** 从海报里发现一部作品，沿着关联关系找到整个系列；边看边向 AI 提问，把喜欢的片段留下来，再分享给同好。追番、阅读、整理和交流，都能在这里自然接上。

追动漫的小朋友，也值得拥有更顺手、更有自己风格的观影方式。

## 为什么做 QCfun

看完一集，想知道下一季在哪里；遇到陌生设定，想查一查又怕被剧透；喜欢某段台词，过几天却找不到当时的位置。对作品的兴趣，往往延伸到播放结束之后。

QCfun 希望把这些零散的小需求连起来：**从“找到一部想看的”，到“慢慢建立自己的作品收藏与观影记忆”。**

## 值得体验的六件事

### 01 · 像逛自己的影院一样发现作品

大幅海报、随作品展开的画面、清晰的内容层次，让封面成为发现入口。首页轮播从**热门推荐、豆瓣高分、季度热门动漫**中按日选取，候选充足时展示七张，同一天保持相对稳定，不会滑着滑着突然重排。

想认真挑选时，可以使用题材、地区、年份等筛选；想追正在看的作品，可以查看时间表、片单和继续观看。片单支持单列与三列切换，让“快速浏览”和“看清信息”各有合适的方式。

### 02 · AI 跟着作品走，问题可以当场问

在详情页打开可调节大小的聊天浮窗；全屏观看时，从侧边聊设定、看点或相似作品。需要推荐时，助手可以结合应用内目录查找作品，并给出可打开的作品入口，减少来回搜索。

“无剧透陪看”会把当前进度和已有记录作为回答约束。缺少逐集资料时应说明信息不足，不能把模型生成的剧情当作可靠事实。具体效果取决于所用模型、已取得的资料和服务权限。

### 03 · 沿着系列星图，找到故事的下一站

一部作品可以成为整个系列的入口。通过关联作品和**系列星图**，查看已有资料中的前传、续作、番外等关系，在发行顺序与关联关系之间切换，再直接进入感兴趣的作品。

已确认关系与同名推断分开标记；发行顺序也不冒充故事时间线。它适合用来整理“这个系列还有哪些作品”，而不是给所有作品强行编出一份观看顺序。

### 04 · 用记忆胶囊，收藏自己的感受

收藏作品之外，还能留下具体的位置：一个视频时间点、一段小说文字、一页漫画，以及当时想写下的感受。

**记忆胶囊把“我喜欢这部作品”变成“我记得为什么喜欢它”。** 下次回看时，可以从自己的记录重新进入作品，让观影与阅读积累成可回访的个人记忆。

### 05 · 动画、漫画、小说，按自己的节奏继续

在同一个应用中整理片单与书架，接着观看或继续阅读。漫画支持配置 AI 模型进行原文覆盖翻译与上色，小说支持翻译和双文对照，让外语阅读有更多选择。

这些是可配置的辅助工具：翻译与生成结果需要判断，上色速度、支持格式及效果取决于模型服务；原始内容与生成内容应能够区分。

### 06 · 看得顺手，也能和同好聊得起来

竖屏下看集数、线路和评论，全屏下使用更完整的播放工具；倍速手势、进度拖动、小窗播放与来源测速，照顾不同观看习惯。可用时优先恢复上次使用的来源，减少重复选择。

弹幕开关与发送合并在同一入口。登录后可以按集评论、回复、@同好和点赞；在消息中心查看收到的互动，添加好友后私信分享作品。好友支持备注、星标置顶和免打扰；收藏仅在你主动开启分享后对已添加的好友可见，默认隐藏。片单和记录可以按需进行账号备份。主题颜色、海报展示与玻璃效果可调整，让这个空间更接近自己的审美。

## 和其他类型的视频软件，有什么不同？

下面比较的是**产品重心与使用方式**。同类产品之间能力不同，部分功能也会重叠；QCfun 的特色在于把这些能力围绕作品组织成连续的体验。

| 软件类型 | 常见产品重心 | QCfun 更强调的体验 |
| --- | --- | --- |
| 平台型流媒体服务 | 在平台提供的片库内发现和观看内容 | 结合可配置来源与个人媒体库，把发现、整理、阅读和作品讨论连在一起 |
| 通用媒体播放器 | 播放本地文件或网络媒体，提供格式与播放控制 | 从作品详情出发，延伸到系列关联、选集来源、AI 问答和个人记录 |
| 自建媒体库系统 | 管理并访问用户自己的媒体收藏 | 提供面向追番与阅读的客户端体验，把媒体库内容接到日常发现与观看流程中 |
| 追番记录与作品资料工具 | 查资料、记录进度、整理收藏 | 让作品资料进一步连接观看入口、上下文助手与可定位的记忆胶囊 |
| 独立 AI 聊天工具 | 通过对话回答问题 | 在详情、播放和阅读场景中携带作品与进度上下文，并连接应用内的作品和操作入口 |

例如，[Crunchyroll](https://www.crunchyroll.com/)介绍其动漫流媒体内容，[VLC](https://www.videolan.org/vlc/)介绍其媒体播放能力，[Jellyfin](https://jellyfin.org/docs/general/about/)强调个人媒体管理与流式访问。这里用这些官方定位帮助理解产品类型，不代表它们缺少表中其他能力。

## QCfun 的创新，落在真实使用的小细节里

- **边看边问**：不用离开当前作品，就能带着进度讨论设定或寻找相似作品。
- **沿关系探索**：从一部番进入整个系列，区分确认资料与推断信息。
- **把感受留在具体位置**：让视频、小说和漫画的收藏有共同的记忆入口。
- **把来源选择讲清楚**：看到来源、线路、集数和测速信息，再决定怎么观看。
- **让外观服务于自己的习惯**：海报式浏览、列表切换、主题和玻璃效果可以按喜好调整。

这些设计的价值，是让“发现 → 观看或阅读 → 理解 → 留下记忆 → 分享”形成一个更完整的使用过程。它们不是对单项功能首创或行业独占的声明。

## 适合怎样的你

喜欢追番，也会读漫画和小说；希望把系列作品整理清楚；想边看边问，又想留下自己的感受；愿意配置自己的来源、媒体库或 AI 模型，希望应用能更贴合个人习惯。

如果你更看重由同一家服务提供并维护的固定片库，平台型流媒体服务有不同的优势。QCfun 的播放覆盖、画质与速度仍取决于可用来源、网络和设备，不承诺任意作品都能播放。

## 0.15.0 · 更清楚的影视目录与聊天

影视页现在支持按类型、来源分类、年份和地区组合查找，逐分类、逐页浏览来源目录。来源返回的数量会标明统计范围和重复可能，避免把样本数当成完整片库。

首页、影视和阅读保留各自的继续观看；「我的」汇总全部。聊天增加草稿、引用、表情和已载入消息搜索，让作品分享更容易接着聊。
